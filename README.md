# Healthcare Anomaly Detection Using K-Means

This project demonstrates how K-Means clustering can be used to identify irregular healthcare submission frequency patterns using synthetic data.

## Overview

Healthcare data systems often process large volumes of submissions over time. Manually identifying irregular submission behavior can be difficult when dealing with high-volume operational data.

This project uses a synthetic healthcare submission dataset to demonstrate how machine learning techniques can help detect abnormal submission frequency patterns.

## Features

- Synthetic healthcare submission dataset
- Timestamp-based submission records
- K-Means clustering for anomaly detection
- Data preprocessing using pandas
- Visualization using matplotlib
- Machine learning workflow using scikit-learn

## Technologies Used

- Python
- pandas
- scikit-learn
- matplotlib
- K-Means Clustering
